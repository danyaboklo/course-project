# Курсовой проект

## Система моделирования генетических конструкций

Курсовой проект посвящён разработке программной системы для моделирования и работы с генетическими конструкциями, генами и последовательностями ДНК.

Проект разрабатывается с использованием принципов объектно-ориентированного программирования и системы контроля версий Git.

## Языки программирования

- C++
- Java

## Основные классы

В проекте используются следующие основные классы предметной области:

- `GeneticConstruction` — генетическая конструкция;
- `Gene` — ген;
- `DnaSequence` — последовательность ДНК.

Структура и функциональность классов будут расширяться по мере выполнения лабораторных работ.
